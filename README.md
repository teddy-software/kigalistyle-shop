## ✅ Features Implemented

### Pages
- **Homepage** — Store name, welcome message, hero banner, featured products and call-to-action button
- **Product Page** — 5 products with images, names, prices and descriptions
- **About Page** — Store description and mission statement
- **Contact Page** — Email, phone number, location and working contact form
- **Cart** — Add-to-cart functionality using Wix built-in store cart

### Functionality
- Responsive mobile-friendly design
- Navigation menu linking all pages
- Add to Cart button on each product
- Working contact form
- Clean and professional UI layout

## ⚠️ Challenges Faced

1. **Image sizing** — Product images had different aspect ratios and needed manual resizing in Wix to keep a consistent grid layout.
2. **Cart setup** — Enabling the Wix Stores cart required installing the Wix Stores app separately from the main editor.
3. **Mobile view** — Some sections needed adjustments in Wix mobile editor to display properly on smaller screens.

---

## 📚 Lessons Learned

1. No-code platforms like Wix allow building professional e-commerce websites quickly without writing any code.
2. Good UI/UX design still matters even in no-code tools — layout, spacing and color choices directly affect user experience.
3. GitHub Markdown is an effective way to document and present project work in a clean and professional format.
4. Planning the store concept and product catalog before building saves significant time during the design phase.
