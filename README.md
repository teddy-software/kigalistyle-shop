## ✅ Features Implemented

### Pages
- Homepage — Store name, welcome message, hero banner, featured products, and call-to-action button
- Product Page — 5 products with images, names, prices, and descriptions
- About Page — Store description and mission statement
- Contact Page — Email, phone number, location, and working contact form
- Cart — Add-to-cart functionality using Wix built-in store cart

### Functionality
- Responsive mobile-friendly design
- Navigation menu linking all pages
- Add to Cart button on each product
- Working contact form
- Clean and professional UI layout

## ⚠️ Challenges Faced

1. Image sizing — Product images had different aspect ratios and required manual adjustment in Wix.
2. Cart setup — Wix Stores app had to be installed separately to enable cart functionality.
3. Mobile view — Some sections required optimization for smaller screens.

---

## 📚 Lessons Learned

1. No-code tools like Wix allow fast development of professional websites.
2. UI/UX design is still very important even without coding.
3. GitHub Markdown is powerful for project documentation.
4. Planning before building saves time and improves quality.
